# Study Settings → Display & Bulk Tasks: Initial Inventory & Gap Verification

## 1. Phase One Inventory

### 1.1 Legacy Ripple Source Files Inspected (`D:\ProjectsWorkSpace\ProjectCode\EnrollnowSpace\ripple`)

#### Display Settings
- `client/components/authenticated/studyPages/settings/display.jsx` (`StudySettingsDisplayLOC`, `StudySettingsDisplay`) — Main Display Settings screen component, locale selector, date format preview, global log checkboxes, potential/enrolled column list management, and Meteor method triggers.
- `client/components/authenticated/studyPages/settings/display/potentialParticipantsColumnList.jsx` (`PotentialParticipantsColumnList`) — Renders `FormSelectRow` items for Potential Participants columns (default 6 columns).
- `client/components/authenticated/studyPages/settings/display/enrolledParticipantsColumnList.jsx` (`EnrolledParticipantsColumnList`) — Renders `EnrolledParticipantsColumnDecision` and `FormSelectRow` items for Enrolled Participants columns (default 3 columns).
- `client/components/authenticated/studyPages/settings/display/enrolledParticipantsColumnDecision.jsx` (`EnrolledParticipantsColumnDecision`) — Checkbox for `"For the remaining columns in \"Enrolled Participants\", choose to show \"Events\" as the headings."` (`enrolledParticipantColumnsShowEvents`, default `true`).
- `client/components/authenticated/studyPages/settings/display/formSelectRow.jsx` (`FormSelectRow`) — Row component with label `Column {n}`, dropdown selector, tooltip for option title, and danger trash delete button (`Remove Column {n}`).
- `both/helpers/participantColumns.js` (`getParticipantColumnOptions`, `getPotentialParticipantDefaultColumns`, `getEnrolledParticipantDefaultColumns`) — Defines the 36 static participant column options plus dynamic study custom variable options (`cv.<name>`), default Potential columns (6), and default Enrolled columns (3).
- `both/helpers/customVariableNameMaker.js` (`makeCustomVariableName`, `lowercaseUnderscoredNoTrim`) — Formats custom variable column values as `cv.<lowercase_underscored_name>`.
- `both/settings.js` & `both/helpers/locale.js` (`isLocaleSupported`) — Supported vs. unsupported locale code definitions (`valid` minus `unsupported`).
- `client/helpers/locale.js` (`getAvailableLocales`, `formatDate`, `getDateInputPlaceholder`) — Locale formatting, example date rendering, and date input format placeholder (`MM/DD/YYYY`, `DD/MM/YYYY`, `YYYY-MM-DD`, etc.).
- `imports/collections/studies/methods/updateStudyLocale.js` (`updateStudyLocale`) — Validates study leadership and `isLocaleSupported(locale)`, persists `locale` on `Studies`.
- `imports/collections/studies/methods/updateStudyGlobalLogSettings.js` (`updateStudyGlobalLogSettings`) — Validates study leadership and persists `showGlobalComments` and `defaultGlobalLogs` on `Studies`.
- `collections/study_customizations.js` (`StudyCustomizations`, `updateStudyCustomizations`, `getStudyPotentialParticipantColumns`, `getStudyEnrolledParticipantColumns`) — Persists `potentialParticipantColumns`, `enrolledParticipantColumns`, `enrolledParticipantColumnsShowEvents` (default `true`), and `statusPageCombinedView` (default `false`) per `studyId`.
- `server/studies/studyImportAndExport.js` (lines 326–335, 923–928) — Exports and imports `displaySettings` (`potentialParticipantColumns`, `enrolledParticipantColumns`, `enrolledParticipantColumnsShowEvents`, `statusPageCombinedView`).

#### Bulk Tasks
- `client/components/authenticated/studyPages/settings/bulk-tasks.jsx` (`StudySettingsBulkTasks`, `StudySettingsBulkTasksLayout`, `BulkTasksTableComp`, `BulkTaskRowItem`, `AddBulkTaskGroupModalComp`, `AddBulkTaskToGroupModalComp`) — Complete Setup Bulk Tasks screen:
  - Lists Bulk Task Groups (`BulkTaskGroups.find({ studyId })`).
  - Opens `AddBulkTaskGroupModal` (`Add Bulk Task Group` / `Edit Bulk Task Group`) with `name` (required), `description` (optional), `triggerActive` checkbox, trigger `eventId` selector (from study's `events`), `"is"` separator, and trigger `action` selector (`completed` / `scheduled`). Supports group deletion with confirmation (`"Are you sure? You will not be able to recover this bulk task group."`).
  - For each group, renders a table of `bulkTasks` (`Title`, `Description`, `Assigned To` initials, and reorder handle) sorted by `rank`, plus a `+ Add Task` button.
  - Opens `AddBulkTaskToGroupModal` (`Add Task` / `Edit Task`) with `name` (required), `description` (optional), and multi-select `assignedTo` (study team members), plus `Delete Task` with confirmation (`"Are you sure? You will not be able to recover this task."`).
  - Supports reordering tasks within a group (`updateBulkTaskOrder`).
- `collections/bulk_task_groups.js` (`BulkTaskGroups`, `BulkTaskGroupTriggerActions = ['completed', 'scheduled']`, `insertBulkTaskGroup`, `editBulkTaskGroup`, `deleteBulkTaskGroup`) — Schema and Meteor methods for Bulk Task Groups; deleting a group cascades deletion to its `BulkTasks`.
- `collections/bulk_tasks.js` (`BulkTasks`, `addBulkTask`, `editBulkTask`, `deleteBulkTask`, `updateBulkTaskOrder`) — Schema and Meteor methods for Bulk Tasks within a group.

### 1.2 Current EnrollNow Source Files Inspected (`d:\ProjectsWorkSpace\ProjectCode\EnrollnowSpace\EnrollNowApp`)

- `frontend/microfrontends/study/src/components/StudySettingsWorkspace.tsx` — Renders sidebar navigation for all Study Settings submenus (`details`, `display`, `bulk_tasks`, etc.), but currently renders only `StudySettingsDetails` when `activeSubmenu === 'details'` and shows a "coming soon" placeholder for `display` and `bulk_tasks`.

- `backend/enrollnow-study-service/src/main/java/com/enrollnow/study/models/Study.java` — JPA entity for `enrollnow.studies`; already contains `locale` (`VARCHAR(20)`), `showGlobalComments` (`boolean`), and `defaultGlobalLogs` (`boolean`).
- `backend/enrollnow-study-service/src/main/java/com/enrollnow/study/models/StudyRequirement.java` — JPA entity for `enrollnow.study_requirements`; contains `configuration` (`jsonb`) which already stores `events`, `customVariables`, `bulkTaskGroups`, `bulkTasks`, and other study configuration collections.
- `backend/enrollnow-study-service/src/main/java/com/enrollnow/study/services/StudyConfigurationService.java` — Manages default configuration creation, cloning, full import, and incremental component import (`bulkTaskGroups`, `bulkTasks`, `events`, `customVariables`), but lacks dedicated Display Settings and Bulk Tasks CRUD/reordering service methods.
- `backend/enrollnow-study-service/src/main/java/com/enrollnow/study/services/StudyService.java` & `StudyController.java` — Manages study-level operations, RBAC (`STUDY_SETTINGS_MANAGE` / `STUDY_ADMIN` / `canManageSiteAdmins`), and tenant isolation, but lacks endpoints for Display Settings and Bulk Tasks.
