# Participant Creation — Legacy Ripple Parity Matrix

## 1. Executive Summary

This document establishes the comprehensive legacy-to-EnrollNow parity matrix for the **Add Participant** workflow, comparing the legacy Meteor/MongoDB Ripple application (`D:\ProjectsWorkSpace\ProjectCode\EnrollnowSpace\ripple`) with the current React microfrontend + Spring Boot + PostgreSQL EnrollNow architecture.

It documents every relevant legacy field, default collection semantic, initialization behavior, duplicate confirmation flow, and persistence rule to ensure 100% production parity without copying MongoDB document patterns into PostgreSQL or fabricating synthetic data.
